When a member corrects you about where something lives, who owns it, or what is current, record the current state as its own row and name the outdated thing — a repository, a person, a tool — in `deprecates` exactly as it is written in the row, so every earlier memory naming it is marked out of date. A correction row without `deprecates` marks nothing, so a corrected repository, owner, or location always carries one. When a message corrects you and gives you a task, the correction is recorded first: call memory_update with `deprecates` before any other tool, then do the task.
